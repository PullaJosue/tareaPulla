10. LAS VARIABLES EN JAVA FUNCIONAN COMO CONTENEDORES PARA ALMACENAR DATOS.
 LOS TIPOS COMUNES SON STRING (TEXTO ENTRE COMILLAS DOBLES), INT (NÚMEROS ENTEROS), FLOAT (DECIMALES),
  CHAR (UN CARÁCTER ENTRE COMILLAS SIMPLES) Y BOOLEAN (VERDADERO O FALSO).P
 ARA DECLARARLAS SE UTILIZA LA SINTAXIS TIPO NOMBRE = VALOR;. EL VALOR SE PUEDE ASIGNAR DESPUÉS 
 Y SE PUEDE MODIFICAR SOBRESCRIBIENDO EL ANTERIOR.

 Cadena nombre = "John";
Sistema.fuera.imprimir(nombre);

int miNum = 15;
Sistema.fuera.imprimir(miNum);

int miNum;
miNum = 15;
Sistema.fuera.imprimir(miNum);

int miNum = 15;
miNum = 20;  // myNum ahora es 20
Sistema.fuera.imprimir(miNum);
